HR Attrition Analysis Dashboard (Excel)
Project Overview

This project analyses employee resignation data to identify attrition patterns and trends across departments, job roles, demographics, performance ratings, and resignation reasons. The objective is to help HR teams improve workforce planning, employee retention, and engagement strategies.

Dataset
Total Records: 5,000 Employee Resignations
Fields Included:
Employee Information
Department & Job Role
Date of Joining & Exit
Performance Rating
Resignation Reason
Location

Determined the most common resignation reasons.
Analysed attrition across age groups and performance ratings.
Examined resignation trends over multiple years.
Provided insights to support employee retention strategies.
