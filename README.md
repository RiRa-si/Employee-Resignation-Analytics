# HR Attrition Analysis Dashboard (Excel)

## Overview
This project analyses employee resignation data to identify attrition trends and patterns across departments, job roles, age groups, performance ratings, locations, and resignation reasons.

The goal is to help HR teams understand workforce turnover and support employee retention strategies through data-driven insights.

## Dataset
- 5,000 employee resignation records
- Employee demographics, department, job role, performance rating, joining and exit dates, resignation reason, and location

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Dashboard Design

## Data Preparation
- Converted date fields to date format
- Calculated employee tenure
- Created age groups
- Extracted exit year for trend analysis
- Cleaned and validated data

## Dashboard KPIs
- Total Resignations
- Average Age
- Average Tenure
- Average Performance Rating

## Analysis Performed
- Department-wise Attrition Analysis
- Job Role vs Resignation Reason Analysis
- Performance Rating Analysis
- Age Group Analysis
- Location-wise Analysis
- Yearly Resignation Trend

## Key Insights
- Identified departments with the highest attrition.
- Analysed the most common resignation reasons.
- Examined resignation trends over time.
- Compared attrition across age groups and performance ratings.
- Generated insights to support workforce planning and retention initiatives.
